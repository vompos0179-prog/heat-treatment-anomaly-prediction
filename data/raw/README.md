# 원본 데이터 안내

이 저장소에는 원본 `data.csv`를 포함하지 않습니다.

- 데이터셋: KAMP 열처리 품질보증 AI 데이터셋
- 공식 주소: https://www.kamp-ai.kr/aidataDetail?DATASET_SEQ=60
- 원본 파일: `data.csv`
- 파일 크기: 약 540MB
- 인코딩: cp949

## 배치 위치

원본 데이터를 내려받은 뒤 아래 위치에 배치합니다.

```text
data/
└─ raw/
   └─ data.csv
```

## 공개하지 않는 이유

1. KAMP 이용 조건을 준수하기 위해 원본 자체를 재배포하지 않습니다.
2. 파일 크기가 약 540MB로 GitHub 일반 저장소에 적합하지 않습니다.
