# 4단계 보완 — Boxplot(IQR) 통계 이상치 분석 설명

## 1. 이 파일은 왜 만들었나?

기존 4단계는 **Isolation Forest(IF)**를 이용한 머신러닝 이상탐지입니다.

이번 `4단계_참고_온도IQR_이상치탐색.py`는 기존 4단계를 바꾸는 코드가 아니라,
강사 피드백인 **“그룹별로 묶어서 비교 후 이상치 확인(통계적으로 접근)”**을 확인하기 위해 추가한 통계 분석 코드입니다.

즉,

```text
기존 4단계
→ Isolation Forest 머신러닝 분석

추가 분석
→ Boxplot / IQR 통계적 이상치 분석
```

두 결과를 나중에 서로 비교하기 위한 목적입니다.

---

## 2. 어떤 데이터를 사용하나?

원본 파일:

```text
data/raw/data.csv
```

사용 센서:

```text
솔트조 온도 1 Zone
솔트조 온도 2 Zone
```

소입로 1~4 Zone은 이번 Boxplot 분석에는 넣지 않았습니다.

이번 분석의 주 대상이 **솔트조**이기 때문에 솔트조 2개 Zone만 사용합니다.

---

## 3. 어느 기간을 분석하나?

원본의 **1월~7월 전체 작업**을 사용합니다.

단, 작업을 다음 3개 기간으로 나눠 결과를 따로 보여줍니다.

| 기간 | 역할 |
|---|---|
| 1~4월 | 기준작성 구간 |
| 5월 | 조건점검 구간 |
| 6~7월 | 후속비교 구간 |

기간은 기존 2단계와 동일하게 **배정번호의 첫 기록 월**을 기준으로 정합니다.

예를 들어 한 작업이 4월 말에 시작해서 5월까지 이어지더라도,
첫 기록이 4월이면 그 작업 전체를 `1~4월` 작업으로 봅니다.

---

## 4. Boxplot에서 무엇을 그룹으로 묶었나?

### 주 분석

가장 중요한 분석 단위는:

```text
배정번호 × 센서
```

입니다.

예:

```text
배정번호 139116
+ 솔트조 온도 1 Zone
```

이 하나의 그룹입니다.

같은 배정번호라도 Zone 1과 Zone 2는 따로 계산합니다.

즉, 서로 다른 작업의 온도를 한꺼번에 섞어서 Boxplot 기준을 만드는 것이 아니라,
**각 작업 안에서 그 작업의 온도 분포를 기준으로 이상치를 확인**합니다.

---

## 5. Boxplot 기준은 어떻게 계산하나?

각 `배정번호 × 센서` 그룹에서 다음 값을 계산합니다.

```text
Q1     = 25% 지점
Median = 중앙값
Q3     = 75% 지점

IQR = Q3 - Q1
```

그리고 일반적인 Tukey Boxplot 기준인:

```text
하한 = Q1 - 1.5 × IQR
상한 = Q3 + 1.5 × IQR
```

을 계산합니다.

온도가:

```text
하한보다 낮거나
상한보다 높으면
```

그 기록을 **Boxplot 통계 이상치 후보**로 표시합니다.

중요:

> 이 값은 실제 고장 기준이나 설비 허용오차가 아닙니다.  
> 통계적으로 같은 그룹 안에서 유난히 떨어져 있는 값을 찾기 위한 기준입니다.

---

## 6. 기존 A1과 무엇이 다른가?

A1은:

```text
현재 온도
vs
직전 10분 중앙값
```

을 비교합니다.

즉 시간에 따라 기준값이 계속 움직입니다.

반면 이번 Boxplot 방식은:

```text
한 작업 전체의 온도 분포
```

를 먼저 만든 뒤,

```text
Q1 - 1.5×IQR
~
Q3 + 1.5×IQR
```

밖에 있는 기록을 찾습니다.

따라서 둘은 비슷한 통계 개념을 사용해도 보는 관점이 다릅니다.

```text
A1
→ 직전 10분과 비교
→ 시간 흐름 중심

Boxplot
→ 같은 작업 전체 분포와 비교
→ 그룹 분포 중심
```

---

## 7. 60초 조건은 왜 들어가 있나?

Boxplot 자체는 원래 **한 점 한 점의 이상치**를 찾는 방법입니다.

하지만 기존 프로젝트의 A1 / A2 / IF 결과와 비교하기 쉽도록,
Boxplot 이상치도 추가로 구간화했습니다.

규칙:

```text
Boxplot 이상치 후보끼리
실제 시각 차이 <= 2초
→ 같은 구간으로 연결

마지막 후보 시각 - 첫 후보 시각 + 1초 >= 60초
→ 60초 이상 조사 후보 구간
```

이 60초 조건은 **Boxplot 공식이 아닙니다.**

기존 프로젝트에서 사용하던 조사 후보 구간 규칙과
비교하기 위해 추가한 조건입니다.

그래서 결과 파일을 볼 때는:

```text
Boxplot 기록단위 이상치
```

와

```text
60초 이상 Boxplot 조사 후보 구간
```

을 구분해서 봐야 합니다.

---

## 8. 보조 분석은 무엇인가?

주 분석 외에 하나를 더 계산합니다.

각 배정번호마다 센서 온도의 **중앙값 1개**를 뽑습니다.

예:

```text
139116 / 솔트조 1 Zone / 작업 중앙값 331.9℃
139417 / 솔트조 1 Zone / 작업 중앙값 332.1℃
141893 / 솔트조 1 Zone / 작업 중앙값 333.0℃
```

그다음 같은 기간의 작업 중앙값끼리 다시 Boxplot으로 비교합니다.

예:

```text
6~7월
+ 솔트조 온도 1 Zone
+ 36개 작업의 작업 중앙값 비교
```

목적은:

> 순간적으로 튄 기록이 아니라,  
> **작업 전체의 운전 온도 수준 자체가 다른 작업이 있는지 확인**

하는 것입니다.

```text

정답 이상
Boxplot이 IF보다 정확하다
```

이번 Boxplot 결과도 **통계적으로 눈에 띄는 후보를 찾는 분석**으로 해석합니다.
