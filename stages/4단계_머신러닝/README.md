## 2. 분석 흐름

### 2-1. 기간을 어떻게 나누는가

2단계 종합본과 동일하게 **작업의 첫 기록 월**로 작업 전체 기간을 정한다.

| 기간 | 월 | 역할 |
|---|---|---|
| 기준작성 | 1~4월 | Isolation Forest 학습 및 점수 분포 기준 작성 |
| 조건점검 | 5월 | 99%, 99.5%, 99.9% 기준의 조사 후보 양을 비교 |
| 후속비교 | 6~7월 | 5월에서 고정한 조건을 변경하지 않고 적용 |

작업이 월 경계를 넘어가더라도 작업을 둘로 나누지 않는다.

---

### 2-2. Isolation Forest가 보는 값

대상 센서는 발표 주 대상인 솔트조 온도 2개다.

- `솔트조 온도 1 Zone`
- `솔트조 온도 2 Zone`

각 기록마다 다음 4개 특성을 사용한다.

| 특성 | 의미 |
|---|---|
| 현재 온도 | 그 시점의 실제 온도 수준 |
| 현재 온도 - 직전 최대 10분 중앙값 | 최근 평소 수준에서 얼마나 벗어났는지 |
| 직전 최대 5분 표준편차 | 최근 온도가 얼마나 흔들렸는지 |
| 직전 기록 대비 초당 변화량 | 바로 전 기록에서 얼마나 빠르게 변했는지 |

현재 기록을 기준값 계산에 미리 포함하지 않고, **과거 기록만 사용**한다.

IF 판정 가능 기록은 직전 최대 10분에서 **유효 기록 300개 이상**이 있고, 네 특성을 모두 계산할 수 있어야 한다.

---

### 2-3. Isolation Forest 설정

| 항목 | 값 |
|---|---|
| 모델 | `IsolationForest` |
| 트리 수 | 300 |
| random_state | 42 |
| 최대 학습 행 | 센서별 200,000행 |
| 학습 기간 | 1~4월 |
| 조건점검 | 5월 |
| 후속 적용 | 6~7월 |
| 최종 고정 분위수 | **99.9%** |

99.9%를 "정답 임계값" 또는 "최적값"이라고 부르지 않는다.  
5월에서 99%, 99.5%, 99.9%를 비교했을 때 조사 후보 규모가 어떻게 달라지는지 확인하고, **후속 조사 목록을 과도하게 넓히지 않기 위한 고정 조건**으로 선택한 것이다.

## 5. A1·A2·IF 공통 판정범위

### 5-1. 왜 같은 범위에서 비교하는가

A1, A2, IF는 판정에 필요한 과거 기록 조건이 서로 다르다.  
각 방법이 자기 판정 가능 기록을 분모로 쓰면 숫자를 바로 비교하기 어렵다.

따라서 최종 비교는:

> **A1·A2·IF 세 방법과 솔트조 1·2 Zone이 모두 판정 가능한 6~7월 원본 기록**

만 사용한다.

공통 판정 가능 범위:

- 기록 수: **770,509개**
- 실제 시간: **786,042초** (약 218.3시간)

---

### 5-2. 공통 범위 기록 단위 비교

`솔트조 2센서 통합`은 이벤트 개수가 아니라 **원본 기록 행 수**다.  
한 시점에서 Zone 1·2 중 하나라도 해당 방법의 60초 이상 선정 구간에 속하면 그 방법의 양성 기록으로 센다. 두 Zone이 동시에 해당돼도 원본 행은 1번만 센다.

| 방법/겹침 | 기록 수 | 실제 시간 |
|---|---:|---:|
| A1 양성 | **590** | 598초 |
| A2 양성 | **7,215** | 7,356초 |
| IF 양성 | **828** | 844초 |
| A1 ∩ A2 | **0** | 0초 |
| A1 ∩ IF | **178** | 179초 |
| A2 ∩ IF | **0** | 0초 |
| A1 ∩ A2 ∩ IF | **0** | 0초 |

이 결과는 "어느 방법이 맞고 틀리다"를 뜻하지 않는다.  
각 방법이 **서로 다른 형태의 변화를 조사 후보로 잡고 있다**는 비교 결과다.

## 7. 설비 단위 비교 (G02)

센서별 구간을 비교하는 것만으로는 같은 솔트조 설비의 Zone 1·2에서 발생한 구간을 따로 세게 된다.

설비 단위에서는 같은 작업의 솔트조 1·2 Zone 선정 구간이:

- 서로 겹치거나
- 앞 구간 종료와 다음 구간 시작이 **2초 이내**

이면 같은 설비 구간으로 합친다.

A1·A2는 3단계에서 이미 만든 `추가_설비그룹_이벤트.csv`를 그대로 사용하고, IF만 같은 2초 규칙으로 합친다.

| 비교 | 첫 방법 설비 구간 | 두 번째 방법 설비 구간 | 공통 구간 | 공통 작업 |
|---|---:|---:|---:|---|
| **A1 vs IF** | A1 6 | IF 5 | **각 2구간** | **2개 작업 — 139116, 139417** |
| A2 vs IF | A2 33 | IF 5 | 0 | 0 |
| A1 vs A2 | A1 6 | A2 33 | 0 | 0 |

센서 단위 A1/IF 공통은 1개지만 설비 단위에서는 2개가 되는 이유는, 설비 비교에서는 Zone 1·2를 하나의 솔트조 설비로 합쳐 보기 때문이다.

figures_A1_IF_비교/

## 12. 한 장 요약

1. **1~4월 학습**  
   솔트조 1·2 Zone을 Isolation Forest로 학습한다.

2. **5월 조건점검**  
   99%, 99.5%, 99.9% 기준을 비교하고 99.9%를 고정한다.

3. **6~7월 고정 적용**  
   Zone 1은 60초 이상 IF 조사 후보 0건, Zone 2는 5건(4개 작업)이 남았다.

4. **3단계와 같은 범위에서 비교**  
   A1·A2·IF 모두 판단 가능한 770,509개 기록만 사용한다.

5. **기록 단위 결과**  
   A1 590개, A2 7,215개, IF 828개. A1·IF 공통 178개, A2·IF 공통 0개.

6. **설비 단위 결과**  
   A1 6구간, IF 5구간이며 두 방법 공통 작업은 **139116, 139417** 두 작업이다.

7. **해석**  
   세 방법의 결과 차이는 서로 다른 변화 형태를 잡는다는 의미로 보고, 실제 고장·불량·오탐 여부는 이 단계에서 확정하지 않는다.
