## 이번에 바꾼 내용

이전에는 IF의 판정 가능 범위를 5단계에서 다시 계산하고, IF 후보 수 일부를 4단계 요약표에서 가져왔다. 이제는 최신 4단계가 저장한 **기록별 IF 판정**을 읽어 같은 시각의 A1·A2 판정과 직접 비교한다.

최신 4단계는 직전 10분에 유효한 기록 300개 이상을 요구한다. 5단계는 이 조건을 별도로 계산하지 않고, 4단계의 `IF_valid`를 그대로 사용한다. 과거 실행의 240개 조건을 현재 계산에 사용하지 않는다.

이번 범위는 **5-1 주분석과 5-2 IQR 비교**다. 품질 연결과 XGBoost는 다시 실행하지 않는다.

그림 없이 표만 계산하려면 두 번째 명령에 `--skip-plots`를 붙인다. 다른 기준 파일을 쓰려면 `--config "기준파일경로"`를 지정한다. `--output`은 새 결과 폴더를 직접 지정할 때 사용한다.

## 무엇을 어떻게 비교하는가

1. 같은 배정번호의 3단계와 4단계 기록 시각을 전부 대조한다. 행 순서나 시각이 다르면 계산을 중단한다.
2. 솔트조 1·2존에서 **A1·A2·IF 모두 판정 가능한 기록**만 비교한다. 판정 불가는 분자와 분모 양쪽에서 제외한다.
3. 각 방법에서 1·2존 중 하나라도 최종 후보이면 그 원본 행을 한 번 센다. 두 존이 동시에 후보여도 두 번 세지 않는다.
4. A1과 IF가 함께 표시한 행, A1만 표시한 행, IF만 표시한 행을 같은 행에서 직접 센다.
5. IQR도 이 공통 기록 범위에 제한한다. IQR의 기존 60초 선정 조건은 유지하며, 공통 범위로 줄어든 구간에 60초 조건을 다시 적용하지 않는다.

**후보 기록 비율 = 후보로 표시한 기록 수 ÷ 공통으로 판정 가능한 기록 수 × 100**

**Jaccard = 두 방법이 함께 표시한 기록 수 ÷ 어느 방법이든 표시한 기록 수**

Jaccard는 두 방법이 얼마나 겹치는지 보여준다. 실제 고장 정답에 대한 정확도·재현율이 아니다. 공통 후보가 진짜 고장이고 단독 후보가 오탐이라는 뜻도 아니다.

## 구간 수와 시간 읽기

- **센서 구간**과 **설비 구간**을 구분한다. 같은 시간에 두 센서가 표시되면 설비 기준에서는 하나로 합쳐질 수 있다.
- 설비 구간은 최신 4단계의 21번 표를 기준으로 확인한다. 22번 표와 비교할 때는 같은 정의를 사용한다.
- **구간 범위 시간**은 시작부터 끝까지의 범위다. 연결 과정에서 포함된 짧은 비후보 시간도 들어갈 수 있다.
- **양성 노출 시간**은 앞 기록의 후보 상태에 실제 다음 기록까지의 간격을 가중한 값이다. 5초 이내의 간격만 사용하며 마지막 기록에는 다음 시간 길이를 붙이지 않는다.
- 후보 기록 비율이 주 지표이며, 위 두 시간 값을 기록 수나 실제 고장 시간으로 바꾸어 읽지 않는다.
