# 5단계 평가 — A1 규칙과 Isolation Forest 비교

## 목적

같은 6~7월 공정 기록을 대상으로 A1 통계 규칙과 Isolation Forest가 어떤 기록과 설비 구간을 각각 지목하는지 비교합니다.

이 단계의 목적은 **정확도 측정이 아니라 방법 간 공통점과 차이를 확인하여 조사 우선순위를 만드는 것**입니다.

> 실제 고장 정답 라벨이 없으므로, 공통 탐지 비율이나 겹침 비율을 정확도·정밀도·재현율로 해석하지 않습니다.

## 비교 범위

- 기간: 2022년 6~7월
- 작업 수: 36작업
- 두 방법 모두 판정 가능한 공통 기록: **770,509개**

## 핵심 결과

| 지표 | A1 | Isolation Forest | 함께 |

## 대안 방법 비교

후보가 지나치게 많아 실제 조사 우선순위 용도로는 비효율적이라고 판단했습니다.

### XGBoost 품질 분류

- 평가: 6~7월

따라서 XGBoost 품질 분류는 주 결과로 채택하지 않았습니다.

## 해석 주의

- 두 방법이 함께 지목했다고 실제 고장이라는 뜻이 아닙니다.
- 한 방법만 지목했다고 오탐이라는 뜻도 아닙니다.
- 겹침 정도는 탐지 정확도가 아닙니다.
- 6~7월은 완전히 독립된 신규 검증 데이터가 아니라 **회고적 비교 구간**입니다.

## 보전 관점의 의미

1. 두 방법이 함께 지목한 시간대를 먼저 확인
2. 한 방법만 지목한 시간대를 다음 순서로 확인
3. 정비 기록·작업 일지·현장 상태와 대조
4. 실제 원인이 확인되면 향후 정답 데이터로 축적

즉, 5단계의 최종 산출물은 **고장 판정표가 아니라 조사 순서를 좁혀 주는 비교 결과**입니다.
