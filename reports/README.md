# reports — 실행 결과가 저장되는 곳

각 단계 코드를 실행하면 이 폴더 아래에 `단계 이름/실행시각/` 폴더가 새로 만들어지고, 표(CSV)·그림(PNG)·`실행정보`·`완료.txt`가 저장됩니다. 기존 결과를 덮어쓰지 않습니다.

| 단계 | 결과 폴더 |
|---|---|
| 1단계 | `reports/1단계_전처리_전체실행/<실행시각>/` |
| 2단계 | `reports/2단계_평소모습_종합/<실행시각>/` |
| 3단계 ① 재현본 | `reports/3단계_이상구간_팀코드재현/<실행시각>/` (기록별 판정 `검증용_기록라벨/*.npz` 포함) |
| 3단계 ② 정리본 | `reports/3단계_이상구간/<실행시각>/` |
| 3단계 공통 범위 비교 | `reports/3단계_공통범위_비교/<실행시각>/` |
| 4단계 | `reports/4단계_머신러닝/<실행시각>/` |
| 5단계 | `reports/5단계_평가/…` |
| 6단계 | `reports/6단계_품질표기/<실행시각>/` |

`완료.txt`가 없는 폴더는 자기 점검을 통과하지 못한 실행입니다. 결과로 쓰지 않습니다.
