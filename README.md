## 🎯 문제 정의

열처리 공정에는 작업마다 수만 행의 초 단위 기록이 쌓이지만, 제공 데이터에는 공식 경보 기준이나 실제 고장 발생 시점이 없습니다.

따라서 프로젝트의 질문을 다음처럼 정의했습니다.

> **“방대한 온도 기록에서 담당자가 먼저 확인해야 할 작업과 시간대를 자동으로 좁힐 수 있는가?”**

초기에는 온도 이상과 불량률의 직접 관계를 분석하려 했지만, 품질 데이터가 작업 단위 합계만 제공되어 **불량이 발생한 시각·설비·Zone을 연결할 수 없었습니다.**  
이에 최종 목적을 **고장 예측 자체보다 ‘이상 후보 탐지 → 조사 우선순위 지원’**으로 재정의했습니다.

## 🔎 핵심 방법

### A1 — 직전 10분과 비교하는 통계 규칙

A1은 현재 온도를 같은 작업의 **직전 10분 중앙값**과 비교합니다.

이상 후보는 아래 조건을 함께 만족할 때 표시합니다.

1. 직전 10분 대비 차이가 1~4월의 평소 흔들림(`1.4826 × MAD`)의 **4배 이상**
2. 솔트조 실제 온도 차이가 **0.3℃ 이상**
3. 후보 기록 간격이 **2초 이하**면 같은 흐름으로 연결
4. 해당 상태가 **60초 이상** 지속

`MAD`는 중앙값 기준의 흔들림 크기로, 큰 값 몇 개에 표준편차보다 덜 영향을 받습니다.

### Isolation Forest — 시계열 특성을 함께 보는 머신러닝

각 Zone에 대해 다음 4개 특성을 사용합니다.

- 현재 온도
- 직전 10분 중앙값과의 차이
- 직전 5분 표준편차
- 초당 변화량

1~4월 기록으로 Isolation Forest를 학습하고, 5월에서 후보 기준 99% / 99.5% / 99.9%를 비교한 뒤 **99.9% 기준을 고정**하여 6~7월에 적용했습니다.

### 6~7월 공통 비교 범위

| 시간대가 겹친 설비 구간 | **2개** |
| 최종 우선 조사 목록 | **7작업 · 9곳** |

### 해석

- **A1**은 같은 작업의 직전 상태에서 갑자기 벗어나는 변화에 민감했습니다.
- **IF**는 드문 온도 수준, 흔들림, 변화량의 조합에 반응했습니다.
- 두 방법이 함께 지목한 구간은 **139116, 139417** 두 곳입니다.
- 공통 구간을 먼저 확인하고, 한 방법만 지목한 구간을 다음 순서로 확인하는 **조사 우선순위**를 제안했습니다.

> 공통이라고 실제 고장인 것은 아니며, 한 방법만 지목했다고 오탐인 것도 아닙니다.
