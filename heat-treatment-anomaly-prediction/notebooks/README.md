## Notebook 작성 규칙

각 Notebook 첫 부분에 아래를 적습니다.

- 분석 목적
- 사용 데이터
- 주요 변수
- 분석 방법
- 이 분석이 필요한 이유

각 주요 결과 뒤에는 아래를 적습니다.

- 관찰된 결과
- 해석
- 설비 이상/예지보전과의 연결
- 다음 분석으로 이어지는 질문
